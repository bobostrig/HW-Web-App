# Desktop app

Run the native Tkinter version from the project root with:

```powershell
python 04_desktop/app.py
```

Python 3.9 or later with Tkinter is required. The desktop app uses the PNG scene backgrounds in `assets/`; regenerate them from the current `index.html` with `powershell -ExecutionPolicy Bypass -File 04_desktop/render_scenes.ps1` on Windows with Microsoft Edge installed.

The web app remains at the project root in `index.html`.
