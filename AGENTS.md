# Project layout

This project contains a single-file web app and a native Python desktop app. Keep `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` at the project root. `index.html` must stay at the root for GitHub Pages and must remain available as the web app.

- `00_planning/`: notes and sketches
- `01_data/`: data files
- `02_validation/`: hand calculations and test cases
- `03_output/`: screenshots and exported results
- `04_desktop/`: Tkinter desktop app source and scene assets

Save each new file in the appropriate folder based on its purpose. Keep the named root files at the top level.
